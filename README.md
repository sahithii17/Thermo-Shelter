# Thermo Shelter

A polished React + Vite prototype for climate-adaptive shelter generation.

## Run in VS Code
1. Open this `Thermo_Shelter` folder in VS Code.
2. Open Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## What is included
- Climate/site brief
- Multi-year demo climate analysis
- Five visibly different generated shelter concepts
- SVG 2D architectural floor plans
- Interactive Three.js 3D model
- Drag/orbit/zoom controls and first-person inspection
- Interior cutaway mode
- Thermal visualization
- Material specifications
- Thermal verification
- Optimization and final top-two designs
- Downloadable project report

## Important prototype note
The climate dataset is demonstration data and the thermal engine is a simplified physics-informed model for an academic prototype. It is not a professional structural, CFD, EnergyPlus, BIM, or construction drawing package. Real construction should be validated by qualified architects/engineers.
